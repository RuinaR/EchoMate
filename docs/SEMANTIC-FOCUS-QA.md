## 요약 의미와 저장/권한

처음 broad qualifier 후보는 기각했다. 실제 모델의 정상 조건부 요약과 조회 실패/빈 결과를 구분하는 설명을 거절하면서, 산책 희망을 확정 계획으로 바꾼 요약을 허용했기 때문이다. 해당 결과·잘못 저장된 **실험 전용 DB**는 격리 진단 자료로 보존하고 운영에 가져오지 않는다.

실제 GPU는 원문 생성, 동일 raw에 대한 이전/수정 검증과 저장 조건 비교에 사용했다. 요약 실패→본인 전체 원문 선택 fallback의 연결은 기존/추가 Runtime 회귀로 확인했으며 새 GPU→SDK 요약 fallback 전체를 실행한 것으로 주장하지 않는다. 저장하지 않는 fallback은 장기 기억이나 실행 성공을 생성하지 않는다.

일부 충돌 검사는 한국어의 모든 의미·화자·청자·시점·인용 동치를 증명하지 못한다. 실제 출처 ID/일관된 Turn 버전·참가자 동의 epoch와 기존 source 삭제/tombstone 계약을 검증하며, 요약 문구를 새로운 기억·권한·실행 영수증으로 승격하지 않는다. 기존 운영 요약을 소급해 정확하다고 인증하지 않았고 DB migration도 수행하지 않았다. CharacterEpoch/NameVersion은 기존 Runtime 송신 guard를 유지하며, 과거 이름의 모든 요약 의미 보존은 NOT VERIFIED다.
