## 실패 단계와 수정 범위

**이 표현 후보는 넓은 회귀에서 오개입·연결 오류가 늘어 기각했다. 아래는 제품에 채택한 구조가 아니라 검증한 후보와 실패 근거다.**

기존에는 모든 발언을 한 `user` JSON 안의 과거 자료로 전달했다. 비교한 새 방법은 **확인된 peer 후보 흐름이 하나일 때만** 그 흐름의 실제 사람/봇 발언을 `user`/`assistant` 역할로 전달하고 현재 발언을 마지막 `user`의 `current`로 분리한다. 원문·ID·작성자·bot 여부·reply·frame 인덱스는 그대로 둔다. 인용된 과거 발언을 새 실제 발언이나 새 작성자로 만들지 않는다. 외부 질문과 인용 내용은 원문에 함께 남아 모델이 의미를 판단한다. 별도 한국어 절 분석기를 구현했다고 주장하지 않는다.

다른 후보 흐름과 주변 사람 간 발언은 라벨이 있는 자료로 유지하고 이 역할 이력에 합치지 않는다. peer 후보가 여러 개이거나 출처의 작성자/bot 표시가 불완전·모순이면 기존 표현을 유지한다. 명확한 호출의 응답 자격, 직접 호출 관계 판정, 신규 참가자 판단은 바꾸지 않는다. 정책 프롬프트·선택 라벨·탐욕 디코딩·출력 토큰 한도12·단일 Worker도 같다. 역할은 기록의 출처이며 답변 허가가 아니다.

후보 `social_messages.py`는 자료를 수정하지 않는 표현 계층이었다. 역할별 내용이 시스템 정책으로 승격되지 않으며 현재 발언 안의 인용·지시도 한 원문 필드로 남겼다. 후보 구현은 채팅 템플릿의 역할 구분 토큰까지 포함해5200토큰 예산을 검사했다. 실제 source/reply 보호를 유지하며 예산을 맞출 수 없으면 실패했다. 최초 실험과 통합 후보의 실제 입력45개가 완전히 같은지도 GPU 재실행 없이 비교했다. 기각 후 이 모듈과 연동 변경은 공개 실행 경로에 남기지 않으며 사본·테스트는 비공개 실험 자료로 보존한다.

## 최종 검증과 남은 차단 사항

후보 표현/실행 연결 검사66개는 통과했지만 이는 의미 품질 통과가 아니다. 넓은 GPU 회귀의 실패 때문에 후보 모듈·연동 변경을 철회하고 사본·합성 검사 원본을 비공개로 보존했다. `final`이라는 실험 디렉터리 이름도 채택된 제품을 뜻하지 않으며 별도 `candidate-status.json`에 기각을 표시했다.

복원된 전체 실행 소스의 파일별 SHA-256은 시작 코드와 일치한다. 설정·bootstrap·관계/기억 DB·송신 ledger의 SHA-256도4/4 동일하다. 운영 데이터·토큰·모델·LoRA·프로필·동의·기억·알림·GPU 큐·UI는 변경하지 않았다. 복원 후 전체 **602개 OK75.907초**를 마감했다. `PYTHONPATH=src;tests;tools`에서 `.venv-gemma4/Scripts/python.exe -m unittest discover -s tests -q`로 실행했고 `regression-restored.log`에 보존했다. 후보 검사의 통과 수를 제품 회귀 수에 합산하지 않는다.
