기준일: 2026-10-19. 모델·응답·평가 키·다운로드 로그는 `local_data/adult-qa-20261019/`에만 둔다. 추가 학습은 하지 않는다. 사람의 블라인드 평가 없이 GGUF를 실사용으로 자동 승격하지 않는다.

## 정책·설정·전환

- 성인 모드의 가벼운 비속어/상황 대상 욕설/상호 동의한 비노골적 말장난만 허용한다. 모든 답변에 농담을 강제하지 않는다. 개인 공격·원하지 않는 성적 발언·미성년자·비동의·노골적 성행위 묘사/역할극은 제한한다.
- Discord 채널의 공식 NSFW 설정을 사용하고 스레드는 부모 채널을 따른다. 전송 직전에는 REST로 부모/채널을 다시 확인한다. 확인 실패/권한 변경/설정 변경이면 성인 출력을 취소한다. 연령 제한 채널은 모든 이용자의 실제 나이·동의에 대한 증명이 아니다.
- 일반 채널에서는 성인 정책을 적용하지 않고 기본 모델의 일반 대화로 전환한다. 최근 실제 사람의 명시적 미성년 자기소개·불편 의사에는 보수적으로 성인 농담을 중단한다. 원문을 편집하거나 영구 나이/관계 프로필을 만들지 않는다. 규칙 검사는 보조 방어이며 포괄적 의미 판정/연령 검증이 아니다.
- 여성/남성/중성·성별 없음은 모든 선택지에 공통이다. 자기소개에 필요할 때만 반영하고 말투·능력·귀여움 등에 성별 고정관념을 강제하지 않는다. 기존 HMAC를 먼저 검증한 뒤 누락된 gender만 neutral로 이관하며 원본 파일은 읽는 것만으로 재작성하지 않는다.
- 소유자 ID 검사 후 모델 준비 상태를 표시한다. 작성 중 작업을 취소하고 단일 worker가 끝난 뒤 준비/상태 점검에 성공해야 선택을 저장한다. 실패하면 이전 선택과 정상 객체를 유지한다. 전환 중 들어온 허용 이벤트는 채널별 최신 실제 이벤트를 보류했다가 준비 후 재검사한다. 오래된 응답/삭제된 메시지는 보내지 않는다.
- 지금의 세 선택지는 같은 상주 가중치이므로 GPU 재적재를 요구하지 않는다. GGUF 평가 서버의 시작/종료는 별도 검증 경로이며 앱의 완성된 GGUF hot-swap이라고 주장하지 않는다.

## 실행 중 발견한 문제와 대응

1. 기본4096 컨텍스트/큰 배치는 GPU 여유512MiB 안전선 아래로 내려가 후보를 종료했다. 2048 컨텍스트, batch128/microbatch64, Flash Attention으로 줄여 VRAM 여유를 확보했다. 가중치 정밀도를 바꾸거나 안전선을 낮추지 않았다.
2. 스트림 `[DONE]`에서 HTTP 본문을 끝까지 소비하지 않고 연결을 재사용하던 경로에 연속 요청 오류가 발생했다. EOF까지 소비하고 명시적 Connection close/force_close로 재사용을 막은 뒤 개발 요청의 전송 오류가 사라지는 것을 확인했다.
3. mmap 로딩은 연속 요청 후 호스트 작업 집합이 커져 RAM 여유2GiB 안전선에서 중단됐다. 메모리맵 없는 로딩과 no-host를 시험했다. 짧은4회 시험에서 서버 RSS 약1344~1485MiB, 여유 RAM 약11GiB, VRAM 약7GiB 여유를 관측했다. 짧은 시험은 장시간 누수 부재의 증명이 아니다.
4. 도구의 소스 스냅샷 경로/보고서 들여쓰기 오류와 private `queue.py`의 표준 모듈 이름 충돌을 발견했다. 실패/부분 결과를 보존하고 경로/구문/이름을 수정했다. 모델 품질 실패로 집계하지 않는다.
5. Transformers `close()` 후에도 같은 평가 프로세스의 CUDA 메모리가 남아 후속 GGUF가 VRAM 안전선에서 중단됐다. 해당 부분 결과는 보존하고, 각 엔진이 별도 프로세스/InstanceLease를 사용한 뒤 완전히 종료하는 순차 실행으로 바꿨다. 두 엔진을 한 프로세스에 번갈아 적재하지 않는다.
6. Tk 테스트에서 UI 객체가 다른 스레드의 GC로 늦게 정리되며 프로세스가 종료됐다. UI 스레드에서 예약 poll/콜백/폰트 참조를 해제하는 destroy 경로와 테스트 정리를 추가했다. 사용자 화면 자동 조작은 하지 않는다.

## 평가 설계와 판정 한계

새 합성60문항, 12범주, 개발36/블라인드24를 고정했다. 잡담·유머·동의·기술·절차·사실·정보 부재·공감·다중 화자 맥락·종료·성별/정체성·개인정보를 포함한다. 실제 대화를 복구했다고 주장하지 않는다. 케이스/소스/가중치 출처는 private manifest에 고정한다.

기본/개인 LoRA/기본+성인정책과 각 GGUF의 일반/성인정책을 분리한다. 동일 사례는 같은 사용자 맥락·성별·greedy seed2026으로 비교한다. 초기 Transformers 개발 시험의192/384 토큰 제한 결과는 앱의768 토큰 프로토콜과 섞어 순위를 매기지 않는다. 제한/출력 가드 실패를 품질 저하나 거절로 단정하지 않는다.

블라인드에는 모델 라벨을 숨기고 한국어/문맥/화자·대상/사실성/완결성/길이/유머/경계를 사람이 각각 평가한다. 유머가 불필요한 기술 설명에 농담이 없다고 감점하지 않는다. 자동 길이·한글 수·EOS·코드 울타리는 진단이지 사람 품질 점수가 아니다. 점수 키와 응답은 외부로 보내지 않는다.

NF4와 GGUF 비교는 엔진·양자화 방식도 달라 순수 가중치 효과로 해석할 수 없다. 같은 가중치의 일반/성인정책 비교는 프롬프트 효과를 분리한다. GGUF 간에는 같은 엔진·파일 타입·리소스 설정을 사용한다. 자동 평가는 부적절한 문맥/거짓말/한국어 자연스러움을 인증하지 않는다. 거절 감소만으로 선정하지 않으며 사람 평가와 핵심 능력/안전 검증이 부족하면 기존 기본 모델+정책을 유지한다.

## 지속 대화 경계

신규 진입 확률과 진행 중 대화를 분리한다. 진행 중 실제 대상/주제 증거나 새 질문이 봇에게 향한다는 의미 증거가 있으면 신규 확률을 다시 뽑지 않는다. 민감 분위기/추가 기여 없음/다른 사람끼리/종료는 침묵할 수 있다. 실제 reply와 화자를 구분하고 새 메시지/삭제/권한 변경/모델 변경 중 출력은 재검사한다. await 권한 조회 중 버전이 바뀌는 경쟁 상태도 조회 후 다시 검사한다.

기존 고정 대기 시간으로 대화를 종료하지 않는다. engagement_seconds는 최소1시간의 bounded 문맥 보관 설정으로만 사용하며 대화 종료는 의미 판단에 맡긴다. 이력100턴·최대32채널 등의 메모리 한계는 유지한다. 한도 밖 기억이나 모든 메시지 응답을 약속하지 않는다.

## 자동 품질 판정의 실패와 선정 보류

local-judge-1은 익명화된 정상166응답에7개 이진 기준을 적용했고 모든 정상 응답을 전 기준 충족으로 판정했다. 유머 범주는 조건마다2문항뿐이다. 실패 출력2개는 판정 대상에서 제외됐다. 이 만점 결과를166/168 전체 품질이나 사람 만족도로 보고하지 않는다.

같은 평가기/지시문을 바꾸지 않고 사전 정의한 합성 대조6개를 실제 GPU에서 추가 판정했다. 알려진 오답·불완전 설명·비한국어·불편 의사 무시5개 중 해당 문제를 검출한 것은2개, 정상 대조1개는 통과해 기대한 기준 판정은3/6이었다. 다른 기준을 엉뚱하게 낮춘 사례도 있어 단순 숫자 합산으로 보정하지 않는다. **이 평가기는 모델 선정용으로 부적합하다.** 응답 차이를 사람 기준으로 신뢰할 수준으로 구별했다는 근거가 없으므로 자동 만점으로 품질 동등성/성인 유머 개선/안전을 선언하지 않는다. 결과는 진단용으로만 보존하고 추가 튜닝에 holdout을 쓰지 않았다.

텍스트 완전 일치(품질 점수 아님): 기본 일반↔성인 정책5/23, culturerevolt3/24, HauhauCS5/24. 기본↔개인0/23, 두 GGUF의 성인 정책끼리0/24였다. 응답이 달라졌다는 사실만으로 자연스러움이나 개선은 입증되지 않는다. 정상166개에 동일 visible guard를 사후 적용했을 때 추가 차단0, 열린 코드 울타리0이었다. 이는 설명의 의미적 완결성 검사와 다르다.

**현재 선정:** 기존 개인 모델은 잠정 상태 보존. 성인 유머 선택지는 기존 기본 모델+정책 대안을 사용한다. 두 GGUF의 빠른 생성은 확인했지만 한국어/문맥/정확성/유머의 비열등성은 미확정이다. 사람 블라인드 평가와 실제 서버 QA 전에는 GGUF를 생산 Runtime에 연결하지 않는다. 새 학습은 하지 않았다.

## 최신 진행과 실행 명령

GPU 생성·합성 지속 대화·로컬 자동 판정·판정기 대조 시험을 완료했다. 최종 큐 상태는 `local_data/adult-qa-20261019/queue-4-status.json`이며 원시 결과와 블라인드 키는 로컬에 보존한다. 자동 판정은 대조 시험에서 한계가 확인되어 선정 근거에서 제외한다. 현재 실사용 GGUF 선정은 보류한다. 사용자는 연령 제한 테스트 채널이 없어 이번 단계는 GPU·모의 이벤트까지 진행하도록 선택했다. 새 코드의 실제 Discord 송수신·실계정 성인 채널 테스트와 사람 평가는 아직 없다.

앱을 완전히 종료한 뒤 PYTHONPATH=src 설정:

```powershell
.venv-gemma4/Scripts/python.exe -m unittest discover -s tests -q
.venv-gemma4/Scripts/python.exe tools/evaluate_adult_models.py --output local_data/<새 폴더> --downloads local_data/adult-qa-20261019 --phase dev --budget-policy runtime
.venv-gemma4/Scripts/python.exe tools/verify_adult_conversation.py --output local_data/<새 대화 검증 폴더>
```

실제 GPU+합성 Discord 이벤트와 실제 Discord 서버 송수신을 반드시 구분한다. 평가 중에는 InstanceLease가 다른 EchoMate GPU 시작을 막는다. 성인 정책을 시험하려고 운영 서버/일반 채널의 연령 제한 설정을 자동 변경하지 않는다.
