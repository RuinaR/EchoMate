# 채널별 단일 화자 데이터 및 출력 스타일 규칙
작성일: 2026-10-18
상태: 최신 사용자 결정 / 설계 단계

## 입력 데이터 해석
- messages1.json: **한 채널**에서 내보낸 본인 메시지 기록.
- messages2.json: **다른 한 채널**에서 내보낸 본인 메시지 기록.
- 두 파일의 채널 경계는 유지한다. 원본 JSON에는 channel_id 필드가 없으므로 가져오기 시 사용자 지정 소스 키(channel_1, channel_2 등)로 관리한다.
- 동일 파일에서 시각이 가까운 연속 메시지는 발화 묶음 후보로 삼을 수 있으나, 그 사이에 다른 사람 메시지가 없는지는 알 수 없다. 따라서 검증 없이 반드시 같은 발화라고 단정하지 않는다.
- 파일을 합칠 때 중복 메시지 ID 제거, 시간 형식 표준화, 민감정보 필터, 원본 수정 금지.

## 시간 가중치
- **최근 메시지일수록 말투 재현에 더 높은 가중치**를 부여한다.
- 기본 제안: 시간 감쇠 가중치 `w = exp(-ln(2) * age_days / half_life_days)`, half-life 후보 90/180/365/730일을 평가로 비교.
- 오래된 데이터를 완전히 제거하지 않는다. 별도의 균일 샘플을 섞어 드문 표현/긴 메시지도 보존한다.
- 자료 범위/평가 날짜에 따른 누수를 방지. 최근 일부 데이터는 평가용으로 분리.
- 같은 메시지의 과다 중복 학습/최근 몇 주 데이터만 과잉 반복되는 현상을 제한한다.

## 미디어 메시지
- **Bot은 텍스트 + Discord 기본 Unicode 이모지**만 전송한다.
- GIF, 이미지, 동영상, 음성, 파일 첨부, 스티커, Discord 커스텀 이모지(<:name:id>, <a:name:id>)를 출력하지 않는다.
- 순수 첨부/스티커/GIF 메시지는 말투 모델 텍스트 학습에서 제외한다.
- Discord CDN URL, Tenor/Giphy 링크 등 미디어 전용 본문은 제거/학습 제외 여부를 검사한다.
- 일반 URL은 정책적으로 별도 허용 여부 결정(기본 출력 제한 권장).
- 사용자가 명시한 '디스코드 기본 이모지'는 Unicode Emoji로 해석. Discord 커스텀 이모지는 사용하지 않는다.
- 출력 필터는 LLM 응답에 커스텀 이모지 마크업, 첨부 지시/Markdown 이미지 링크 등을 검사하고 전송 전 차단·정규화한다.
- 학습 데이터의 평문 표정(ㅋㅋ, ㅠㅠ, ㅇㅇ 등)은 이모지/미디어가 아니므로 보존한다.

## QA 계획
1. 동일 파일 연속 메시지와 파일 간 메시지 혼합 방지.
2. 최근 가중치 실험 시 스타일 유사도와 주제 편향 평가.
3. 빈 본문·첨부 전용·GIF 링크·커스텀 이모지 필터 정확성.
4. Discord 기본 Unicode Emoji는 허용.
5. 봇이 이미지/스티커/파일/GIF/커스텀 이모지를 전송하지 않는지 검사.
6. 모든 후보 실험은 사용자 개인정보/원본을 GitHub에 업로드하지 않고 로컬에서 수행.
7. 자료 출처 및 AI 학습 이용 허가 조건 충족 전에는 모델 학습 금지.
