조회 시 동의 버전·실제 기억 행을 보존하고 생성 후/송신 직전에 다시 비교한다. 빈 검색도 같은 질의를 다시 조회해 새 근거가 생긴 경우 오래된 부재 설명을 차단한다. 철회 후 재동의·삭제·정정·만료·원본 무효화는 기존 행/범위 guard와 연결한다. 기능 스냅샷·동의 버전·관계 값·원래 Runtime fresh도 재검사한다. 원격 송신 완료와 DB를 하나의 원자 트랜잭션으로 만들지는 못한다.
