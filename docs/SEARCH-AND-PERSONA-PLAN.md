# EchoMate: 웹 검색과 페르소나 제작 계획
날짜: 2026-10-18. 구현과 계획을 구분한다.
## 웹 검색: 향후 Bot 기능
- 기본 OFF이며 사용자가 활성화한 채널에서만 최신 패치, 뉴스, 일정, 외부 사실 확인에 활용.
- 개인/민감 Discord 메시지를 외부 검색 공급자에게 전송하지 않고, 최소화한 일반 검색어만 전달.
- 결과는 신뢰할 수 없는 외부 자료로 취급. 출처와 날짜 표시, 타임아웃/요청 한도, 실패 시 모르는 사실을 지어내지 않음.
- 실제 검색 공급자/인터페이스는 미구현. 무료 옵션과 약관 평가 후 결정.
## 생성 중 새 메시지
- 새 메시지로 답변이 낡았을 때 평가/생성 재시도. 무한 반복은 금지(초기 최대 2회, 범위 1~3).
- 현재 stale_recovery.py는 보수적으로 내용 변화 시 재생성하며 검증된 비중요 변화만 선택적으로 재사용.
- 실전 전송 잠금 내부에서 상태 버전과 채널 권한을 마지막으로 재확인해야 함. 아직 Discord 연동 미구현.
## 페르소나 제작은 다음 개발 우선순위
1. Style Profile v1: JSON 파일 N개(파일=채널)에서 구어체/짧은 메시지/초성·표현 분포 및 최근 가중치 분석.
2. 기본 Qwen vs 스타일 프로필 적용 Qwen 블라인드 비교, 답변 내용 적합성/형식/반복/자연스러움 평가.
3. 출처 및 사용 허가를 확인한 데이터로만 필요할 때 스타일 예시 검색/QLoRA 실험.
4. 모델/프로필 버전 캐시, 롤백, 읽기 전용 Bot 로딩.
## 이용 조건
- Discord Developer Policy §21은 API 획득 메시지의 AI 학습에 명시적 허가 요구. 데이터 패키지를 소유한다고 AI 학습이 자동으로 허용되는 것은 아님.
- 공식 사용자 데이터 패키지에 정확히 어떤 계약 조항이 적용되는지는 추가 확인이 필요. 허가 여부가 불명확한 자료는 구조·통계 분석 범위에 둔다.
## 현재 검증 상태
- 사용자 Windows 50개 테스트 OK; 로컬 Qwen 문맥 평가 실험 성공.
- 새 재시도 기능 테스트는 작성 및 GitHub 커밋되었으나 Windows 실기기 미검증.
- Discord 연동, 인터넷 검색, 스타일 프로필 생성 및 모델 학습 미구현.
