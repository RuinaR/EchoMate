## 채택한 국소 변경

1. **허용된 관계로 표현**: grounded_social_choices가 이미 validate_social이 거절하는 비참가 resume·비peer continue·pending에서 join을 출력 후보에서 제외한다. 사람/불확실/응답 없음은 유지하고, 유효한 group join은 보존한다. 응답하도록 강제하지 않는다.
2. **현재 입력을 마지막에 배치**: 사회 판단 JSON 값은 동일하게 유지하고 실제 current 뒤에 과거 발언이 남지 않게 한다. 일반 생성·요약에는 적용하지 않는다.
3. **최소 문맥의 중복만 축소**: 기존 보호된 reply쌍·후보·원문 선택을 마친 뒤에도 예산 초과일 때만 Runtime 전용 중복 버전 필드를 제외하고 동일 ID/공통 필드/본문이 모두 일치하는 복사본의 본문을 text_source로 참조한다. pending 본문·충돌 복사본은 그대로 둔다. 참조 생성 뒤에는 더 자르지 않고 native 토큰을 재계산한다. 여전히 초과하면 실패하며 무음 절단하지 않는다. 본문 참조가 모든 자연어 판단에서 의미 동치를 보장한다는 뜻은 아니다.
4. **이름을 명확히 부르는 복귀의 근거 선택**: GGUF의 기존 의미 판단 안에서만, 사람 경계가 있고 현재 설정 이름을 문두에서 부르며 사람 대상 구조적 근거/이름 충돌이 없고 화자의 실제 요청↔봇 reply쌍이 있을 때 작은 근거 view를 사용한다. 부분 이름 별칭을 확장하지 않는다. 동일 Lime이 human/report_only/uncertain/실제 resume anchor 중 고르고 기존 validate_social로 재검사한다. 이름 등장만으로 DIRECT 승격하지 않는다. 인용·무이름·근거 없는 화자는 기존 경로다.
5. **경계 출처 최신성**: 사람 경계의 원문이 판단/생성/송신 사이 바뀌면 오래된 판단을 취소한다. 예상된 stale 취소를 백엔드 고장 횟수로 누적하지 않는다. packet과 stamp는 최초 권한 await 전에 함께 고정한다. await 후 새 stamp를 이전 packet에 붙이던 순서도 수정했다. 정확히 그 순서만 되돌린 CPU counterfactual에서는 권한 대기 중 삭제 후 모델에 진입했고, 수정본은 모델 호출 없이 취소했다.

기각: 관계 후보 제한만 적용, 과거 발언을 마지막에 둔 축소 입력, 예산과 무관한 metadata 상시 제거, 원문 선택 전에 참조 생성. 일부 사례에서 무응답·다른 오류가 남거나 출처 참조가 깨질 수 있어 채택하지 않았다. 프롬프트 예문 암기·무조건 pending 초기화·대상 기준 완화는 하지 않았다.
