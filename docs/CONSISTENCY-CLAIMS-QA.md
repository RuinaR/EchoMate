## 채택·기각·후속 우선순위

- **채택:** 기본 생성의 같은 기억 선택 결과(빈 결과/상위3개 포함) 재검증. 추가 추론 없이 실제 stale 송신을 줄였으며 다른 사용자/무관한 query 변경은 보존했다. 기존 동의·원본 reply·취소·부분 송신의 보호를 유지한다.

- **기각:** 대비 디코딩 운영 적용. 일반 잡담의 일부 관점 차이가 있어도 높은 연산/메모리/지연 비용과 거짓 미래 약속이 남았다. 추출기는 단순2건의 형식 문제가 풀렸을 뿐 운영 신뢰성을 입증하지 못했다.
