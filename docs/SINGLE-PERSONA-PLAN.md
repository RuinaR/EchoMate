# 단일 페르소나 중심 개발 방향 (2026-10-18)

## 최종 사용자 결정
EchoMate v1은 프로젝트 사용자 **본인의 페르소나 단 하나**를 가능한 한 고품질로 재현한다. 다중 페르소나 리스트/친구별 학습·동시 AI 대화는 초기 범위에서 제외한다. 봇 표시는 `EchoMate(서버 닉네임)`을 유지한다. 지정한 하나의 스레드에서만 활동한다.

## 데이터 확보 원칙
- 대상: 본인 작성 메시지, 가능하면 장기간의 텍스트. 다른 사람의 발언은 처음부터 필수 입력으로 가정하지 않는다.
- Discord 공식 웹/데스크톱 앱 검색의 작성자(from:) 필터를 이용해 자신의 과거 메시지를 찾아볼 수 있으나, 대량 파일로 자동 내보내는 기능은 제공되지 않는다.
- 본인이 직접 작성한 별도 예문 또는 사용 허가가 명확한 개인 텍스트 파일은 즉시 입력 가능.
- Discord 공식 계정 데이터 패키지 요청을 유지한다. 당장 수령하지 못해도 합성 데이터로 importer와 분석기를 만든다.
- 일반 사용자 계정의 자동화(self-bot), 사용자 토큰, 비공식 웹 스크래핑·수집 회피는 지원하지 않는다.
- Discord Bot API의 과거 메시지를 AI 학습하거나 Discord 데이터를 관계/사용자 프로파일링에 활용하는 것은 정책 및 명시적 허가 조건을 확인한 후만 검토한다.
- 내보내기 파일이 존재한다는 사실 자체가 AI 훈련 허가를 의미하지 않는다.

## 데이터 가져오기 어댑터 계획
1. manually_authored_examples: 직접 작성한 화자별 예시 (즉시 실험)
2. text_or_json_import: 출처·이용 조건이 확인된 개인 작성 텍스트
3. discord_data_package: 공식 제공 ZIP 구조 파싱 (로컬 preview-only로 시작)
4. consented_conversation_examples: 별도로 사용 허가된 대화·문맥 샘플 (조건부)

Importer는 원본 변경 없이 크기·인코딩·메시지 수·타임스탬프를 확인하고, 필요하면 특정 서버·기간을 필터링한다. 메시지 원문은 Git에 커밋하지 않으며 승인 상태를 기록한다.

## 품질 고도화
- 단일 화자 데이터로 언어 습관(초성/말버릇/문장 길이/자주 쓰는 어휘/메시지 연속 패턴)을 분석
- 실제 존재하지 않는 상대 발언을 정답으로 생성하지 않음
- 기초 모델+프로필 → 허가된 RAG → 허가된 QLoRA 순으로 비교, 품질 지표로 최종 채택
- 실시간 스레드의 현재 톤과 발언자에 맞게 임시 적응하되 Discord API 콘텐츠로 수년치 인물 관계·친밀도를 자동 프로파일링하지 않음
- 한 번에 하나의 활성 페르소나이므로 초기에는 리스트박스가 불필요. 향후 다중 지원 요구 시 별도 기능으로 재검토.

## 즉시 개발할 모듈
- Python 기반 단일 화자 importer/검증기와 합성 데이터 테스트
- Discord 공식 봇 + 로컬 Ollama + 지정 스레드 MVP
- 본인 스타일 편집 및 평가 UI
- 안전한 발언 판단, 중복방지, 재연결, 기록 최소화
