# 사용자 확인 — 오프라인 10~15분

자동 검사만으로 확인하기 어려운 실제 글자 가독성·키보드 이동·파일 선택창·창 크기·사용 흐름만 확인한다. 아래 확인을 아직 사용자가 수행한 것으로 기록하지 않는다. 정식 릴리즈 승인이 아니다.

## 먼저 안전하게 시작

1. 기존 EchoMate가 켜져 있으면 **직접 종료**한다. 다른 앱이나 게임을 종료할 필요는 없다. GPU 모델을 두 번 로딩하지 않도록 한다.
2. 일반 실행 파일 대신 **`EchoMate-Check.vbs`**를 더블클릭한다. 검증용 창을 자동으로 열어 본 것은 아니다.
3. 창 제목에 **오프라인 검증 · 운영 자료와 분리됨**이 있는지 확인한다. 이 창에는 실제 Bot Token을 넣지 않는다.
4. **처음 사용 안내**의 등록창에서 미리 채워진 가상 사용자 ID와 가짜 토큰을 그대로 적용한다.

검증 자료는 `%LOCALAPPDATA%\EchoMate\manual-check`에 저장한다. 기존 운영 `local_data`와 다르다. 창에는 **가상 서버·가상 채널**만 표시하며, 봇 켜기와 목록 새로고침은 실제 연결을 차단한다. 일반 `EchoMate.vbs`는 운영 실행 파일이므로 이번 확인에 사용하지 않는다.

## 확인 목록

- [ ] **처음 사용 안내**: 무엇을 입력하는지 읽기 쉽고, 입력란의 토큰이 가려진다.
- [ ] **대화할 곳**: 가상 채널과 스레드를 고를 수 있다. 채팅·이모지 설정을 바꾸면 미저장 표시가 나타나고 저장 뒤 사라진다.
- [ ] **AI 모델**: 모델 폴더 선택창을 열고 취소해도 설정이 바뀌지 않는다. 보유한 검증된 분할 모델을 고르면 파일 검사와 실제 준비 상태가 구별된다. 모델 파일을 이동·삭제하지 않는다.
- [ ] **성격과 기분**: 캐릭터를 복제해 이름·말투를 바꾸고 저장한다. 가져오기/내보내기는 새 테스트 파일명을 사용하며 기존 파일을 덮어쓰지 않는다. 취소했을 때 원래 값이 유지된다.
- [ ] **로컬 미리보기**: 개인정보 없는 짧은 합성 질문 하나를 보낸다. 준비·처리 표시와 답변을 확인한다. 창을 닫고 GPU 정리가 끝날 때까지 기다린다. 로딩 중 취소는 약25초 걸릴 수 있으며 즉시 물리 중단을 뜻하지 않는다.
- [ ] **사람·기억·예약**: 자료가 없는 상태를 오류나 연결 대기로 오해하지 않게 안내한다. 이 검증 창에는 실제 사용자 자료가 없어야 한다.
- [ ] **진행 상황**: 실제로 수행한 모델 준비·미리보기와 오류를 구분해 보여 준다. 오프라인에서 **봇 켜기**를 누르면 연결 차단 안내가 나오며 실제로 접속하지 않는다.
- [ ] **사용성**: 평소 Windows 배율에서 작은 창·큰 창을 확인한다. 글자가 겹치거나 버튼이 잘리지 않고, Tab·Enter·Esc·스크롤이 예상대로 동작한다. Windows 배율 변경은 사용자가 원하는 경우에만 한다.
- [ ] **종료·복원**: 검증 창을 닫고 같은 `EchoMate-Check.vbs`로 다시 연다. 검증용 설정·프로필이 유지되고 운영 자료는 나타나지 않는다.

모델 준비가 자원 부족으로 거절되면 그 안내를 기록하고 중단한다. 페이지 파일이나 GPU 안전 설정을 바꾸거나 반복 재시도하지 않는다.

## 실패하면

어느 화면에서 무엇을 눌렀는지, 기대한 동작과 실제 동작, 대략적인 시각을 알려 준다. **진행 상황 → 개인정보 없는 진단 저장**으로 만든 `diagnostic-report.json`은 위 검증 자료 폴더의 `bot` 아래에 있다. 토큰·DB·모델·원문 로그는 공유하지 않는다. 화면 캡처가 필요하면 개인 이름·ID·폴더 경로를 가린다.

## 실제 Discord 확인 — 이번에는 실행하지 않음

사용자가 별도로 허용한 이후에만 일반 앱과 별도 테스트 서버에서 확인한다. 명확한 호출·멘션 없는 후속·타인끼리 대화의 침묵·원본 reply·Unicode 반응을 비교한다. 현재 자동 결과와 오프라인 확인으로 실제 Discord 품질이 검증된 것은 아니다.
