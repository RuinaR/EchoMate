# 프로젝트 정의서

문서 날짜: 2026-10-18 / 상태: 최초 설계

## 문제와 비전
EchoMate는 친구들이 사용하는 Discord 서버의 특정 스레드에서 AI 봇임을 밝힌 채 대화한다. 선택된 사람의 **언어 습관과 대화 스타일**을 최대한 자연스럽게 반영한다. 실제 사람과 혼동시키거나 타인의 개인적 비밀을 추측·노출하는 것은 목표가 아니다.

## 확정 요구사항
- 무료 우선, AI 추론은 사용자 Windows PC의 로컬 Ollama에서 수행.
- 최초 대상: 프로젝트 사용자 본인, **단일 화자 메시지 데이터만** 있다는 전제로 시작.
- 추후 친구별 독립 페르소나 데이터/어댑터 추가.
- 페르소나는 검색 가능한 리스트박스에서 선택. 서버 닉네임 기반 `EchoMate(ABC)` 형태로 봇 별칭 갱신.
- 봇은 지정한 하나의 Discord 스레드에서만 메시지 출력. 서버/스레드 식별자는 설정으로 관리.
- 대화 흐름을 관찰해 스스로 참여 여부를 판단. 모든 메시지에 응답하지 않음.
- 현재 대화 맥락 유지, 재시작 후 필요한 최소 상태 복구, 반응 속도 및 안정성 평가.
- 안전한 중지, 발언 쿨다운, 최대 발언량, 명시적 봇 표기.
- 데이터 패키지가 도착하면 로컬에서 관련 서버 자료만 검사/추출할 수 있는 *분석 도구*를 만들 예정(학습 투입은 이용조건 확인 후).
- 설계·구현·테스트·인수인계 문서를 지속 업데이트.

## 데이터의 의미
'단일 화자'란 각 기록에 대상 사용자 본인의 메시지만 있고 대화 상대의 실제 발언이 보이지 않는 상태. 분석 가능한 것은 어휘, 길이, 종결어미, 오타/초성, 시간대, 자기 메시지 연속 패턴 등이다. 다른 사람의 실제 발언이나 질문-답변 관계는 증명할 수 없으며, 생성한 가상 문맥을 원본 사실로 표기하지 않는다.

## 비목표(초기)
- 전체 서버 과거 메시지 크롤링/학습, self-bot, 외부 유료 모델 필수화
- 운영 중 무검증 온라인 파인튜닝
- 다중 페르소나 동시 발언, 음성 통화, 전 서버 자동 대화
- 인간 본인 행세 또는 혼동 유도

## 수용 기준(계획)
1. 대상 thread ID 이외 출력 없음.
2. 봇 자기 메시지/중복 이벤트 루프 없음.
3. 로컬 AI 연결 끊김 시 안전하게 실패하고 자동 스팸하지 않음.
4. 페르소나 변경 시 닉네임·설정과 답변의 대상이 일관됨.
5. 단일 화자 원본에서 가짜 상대 대화를 만들지 않음.
6. 기준 테스트 세트에 대해 스타일 유사도, 문맥 적합성, 무응답 판단, 반복률, 지연 평가 기록.
7. 민감한 로그·설정·데이터가 GitHub에 유출되지 않음.
