# 데이터 확보 대안 — 정식 패키지 도착 전

작성일: 2026-10-18

## 요구
오래된 Discord 서버에 수년치 메시지가 있고, 초기에는 본인 페르소나만 만든다. 다른 참가자들의 데이터 패키지는 확보하지 않는다.

## 경로 비교
| 방식 | 소요/장점 | 제한/판정 |
|---|---|---|
| Discord 공식 데이터 패키지 | 과거 *본인 메시지*를 장기간 포괄 | 신청·전달 지연. 수령 시에도 AI 학습 사용 조건 확인 필요. 주 경로 |
| 본인이 직접 작성하는 예문/스타일 가이드 | 즉시 가능, 표현의 출처 명확 | 자동 기록보다 분량과 다양성이 부족할 수 있음. 즉시 실험용 |
| 이미 권리가 확인된 개인 작성 텍스트/오프라인 로그 | 즉시 가져오기 가능 | 타인 채팅·개인정보 제외, 이용 조건 점검 필요 |
| 특정 스레드의 실시간 메시지에 응답 | Discord 봇 MVP 즉시 확인 | 과거 스타일 학습 데이터가 아님. 이용자 동의·서비스 약관 준수 |
| 서버 메시지 공식 Bot API 과거 조회 | 기술적으로 조회 가능 | AI 모델 훈련은 Discord 명시적 허가 필요. 승인 전 학습 파이프라인에 연결 금지 |
| DiscordChatExporter 사용자 토큰/셀프봇 자동화 | 외부 도구에서 사용 사례 존재 | 계정 제재·약관 위반 위험. EchoMate에서 지원/권장하지 않음 |
| 외부 제공 Export 파일 | 이미 파일을 받은 경우 빠르게 정규화 가능 | 추출 방식·권리·동의·학습 사용 허가 별도 확인; 자동으로 합법화되지 않음 |

## 추천 실무 절차
1. Discord 앱에서 공식 데이터 패키지 신청은 유지한다.
2. 그 사이 합성 데이터 및 *본인이 직접 작성한 예문*으로 봇/페르소나 파이프라인과 평가 기준을 만든다.
3. 사용자가 보유한 기존 텍스트는 민감정보와 출처를 점검한 다음, 허용된 범위에 한해 활용한다.
4. 패키지 도착 시 raw ZIP 자체는 로컬에만 두고, 서버 식별자/본인 작성 메시지 필터와 미리보기를 만든다.
5. 모델 학습과 영속적인 검색 인덱스 생성은 사용 조건 및 권한이 확인된 데이터에만 허용한다.

## 중요한 차이
- 파일로 내보낼 수 있다는 것 != AI 모델 학습이 허용된다는 것.
- 봇이 최근 대화에 답할 수 있다는 것 != 과거 전체 채팅을 인물 프로파일링용 데이터로 누적 가능하다는 것.
- 단일 화자 기록만으로 다른 참여자의 발언과 원인·의도를 복원했다고 주장해서는 안 된다.
