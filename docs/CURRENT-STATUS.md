# 현재 상태

갱신: 2026-10-18. 최신 상태는 이 문서와 `AI-HANDOFF.md` 첫 절을 우선한다.

- 실제 로컬 300/2,500단계 학습 summary 및 기존 A/B 8건을 확인했다. 이번 GPU에서 BF16 60/60/120단계 학습과 생성 비교까지 실행했다. 실험용 후보는 rank8 q/k/v/o 60단계이며 최저 loss의 120단계를 자동 선택하지 않았다. 실사용 페르소나 선정은 보류.
- 일반 LM 학습과 chat-template 추론의 차이, 종료 학습 누락, 짧은 검증 표본 부재를 확인했다. 실제 상대 발언은 존재하지 않으며 만들어내지 않는다.
- 새 도구: 응답 중심 독립 스타일 적응, 짧은 표본 추출, offline NF4/BF16 학습, 안전 중단, optimizer/RNG checkpoint 재개, 순차 큐, 생성/블라인드 비교, 로컬 대시보드.
- 첫 FP16 pilot은 업데이트 전 비유한 gradient로 중단. BF16 실험 정상 완료, optimizer/RNG 상태 복원으로 중단 재개 확인. 기존 어댑터도 실제 적용되며 raw 입력과 chat 입력에서 영향 크기가 다른 것을 관찰했다.
- 단위/회귀 208건 통과(0.715초), 도구 문법 검사 통과. 사람의 말투 유사성, 중단 재개의 비트 단위 동등성, 실제 Discord 품질은 이 테스트로 증명되지 않는다.
- 첫 합성 최종 평가에서 기본 모델/후보 모두 게임 참여 약속, 후보의 절차 설명 미완결이 발견됐다. 이 집합은 개발용으로 은퇴시켰다. evaluator 전용 정책 v2로 기능 한계/절차 완결성을 명시했고 새로운 합성 7건도 실제 GPU 평가 완료. 둘 다 7/7 종료, 최신 문맥 요일 답변, 정보 없음/보안 요청 대응, 실제 참여 불가를 확인했다. 상세 절차도 종료했지만 기술 사실/최신성은 미검증이다. 사람 말투 평가와 실서비스 승인은 없다.
- 사용자가 평가할 문서: `local_data/experiments/style-v2/fresh-final-generation.blind.md`. 누적 대시보드: `local_data/experiments/dashboard.md`. 상세 근거/실패/선정은 `ML-EXPERIMENTS.md`. 이 fresh-final 결과로 다음 튜닝을 하면 해당 집합도 개발용으로 은퇴시킨다.
- 기존 참여·침묵·멘션·대화 지속·취소 관련 코어 코드는 변경하지 않았다. 실제 Discord 송수신·서비스 운영 QA는 미완료.
- 비공개 자료는 전부 `local_data/`. 외부 클라우드 GPU·유료 API·새 원천·GitHub 업로드 없음. 작업 시작 HEAD `7e1e77f`; 변경분 커밋 상태는 WORKLOG 참조.
