Gemma 해제 후 단독 로딩했으며 새 모델 다운로드는 없다. 같은16개 정답×2순서에서 인격 정확도37.5%/일치43.75%, 사실 정확도28.125%/일치25%로 양 축 부적격이다.32개 중14개는 없는 인용 구간/근거 ID 등 계약 위반으로 unknown 처리했다. 형식 실패뿐 아니라 타당한 분석 답변을 불합격 처리하는 의미 오류도 남는다. 사실 실패의 잘못된 pass는0건이지만 많은 미판정/오판 때문에 합격하지 못한다. 이후40답변 재채점·재작성·최종 자료 소비 없이 종료했다. 감사 호출 p50/p95=4.555/6.755초이며 운영 응답 시간에 추가된 비용이 아니다.
