# 실시간 대화 적응 및 점진적 기억 갱신 설계

작성: 2026-10-18
상태: 설계 (코드 없음)

## 목적
유일한 '본인 페르소나'가 지정 Discord 스레드에서 현재 대화 분위기에 적응하고, 운영 중 받은 합법적으로 이용 가능한 피드백과 명시적인 선호를 바탕으로 시간이 지날수록 자연스러워지게 한다. 사용자가 희망한 관계·친밀도 자동 갱신은 Discord API 사용자 관계 프로파일링 제한을 고려해 그대로 구현하지 않는다.

## 중요한 구분
- **SessionTone (일시적)**: 현재 대화에서 호칭·장난·진지함·반응 길이 조절. 종료/TTL 후 폐기하며 다른 채널 기록과 결합해 영구 관계 점수로 만들지 않는다.
- **PersonaStyle (지속적)**: 본인 작성 예문, 직접 제공한 피드백 등 적법하게 이용할 수 있는 자료를 통해 표현 습관·길이·선호를 갱신. 데이터 출처/허가 기록.
- **ExplicitPreference (지속적, 사용자 선택)**: 실제 대화 참여자의 직접 밝힌 호칭/금지 주제/원치 않는 상호작용 설정. 삭제/거부 가능.
- **ProhibitedInference**: Discord API 메시지를 누적해서 각 사용자의 친밀도·관계 점수·성격을 몰래 자동 프로파일링하지 않는다.

## 파이프라인
1. Discord 공식 봇에서 허용된 지정 스레드 현재 메시지 이벤트만 받아온다.
2. 참여자 opt-out, 토큰 권한, 중복 이벤트, 봇 메시지를 먼저 필터링한다.
3. 메모리 TTL이 있는 단기 대화 상태를 갱신한다.
4. 발언 필요성/쿨다운/스팸 예방 판단.
5. 현재 분위기(SessionTone)와 단일 본인 페르소나의 일반적인 표현 습관(PersonaStyle) 및 참여자가 직접 밝힌 선호를 이용해 로컬 Ollama 답변 생성.
6. 응답 품질/지연/반복 메트릭은 개인정보 없는 형태로 로컬 저장.
7. 본인으로부터 받은 명시적 평가·교정에 대해서만 지속 스타일 개선 후보를 생성한다.
8. 교정 후보는 사용자가 검토하고 채택한 후, 버전 관리 가능한 로컬 profile로 반영한다.
9. 모델 가중치는 운영 중 자동 수정하지 않는다. 충분히 허용된 데이터가 쌓이면 별도의 오프라인 LoRA 학습·A/B 평가 후 수동 배포.

## 자동 적응에 관한 기술적 정교화
- 단기 업데이트는 즉시 적용 가능하되, 오래된 관찰에 지나치게 반응하지 않도록 TTL 및 이동평균 같은 완충 장치 고려.
- '농담이 많다'는 현재 대화 스타일 판단은 가능하나, 'A와 나의 친밀도 87'처럼 실제 관계 사실을 추정해 장기 저장하지 않는다.
- 불확실성을 수치화해도 이것이 친밀도에 대한 객관적 근거가 되지 않음.
- 다른 사용자들의 과거 데이터 수집은 v1의 필수요건이 아님.
- 사용자가 직접 제공한 피드백으로 본인 스타일은 누적 개선할 수 있음.

## 테스트
- 현재 대화가 진지해지면 즉시 장난 억제; 다른 세션에서는 이전 추정이 잔존하지 않음.
- 같은 화자에게 여러 번 반응해도 분 단위 채팅 맥락만으로 장기 친밀도 점수가 생성되지 않음.
- 피드백 입력의 출처·승인·롤백·삭제가 기록됨.
- 데이터 사용 허가가 철회되면 파생 인덱스/스타일 학습을 식별해 삭제 또는 재구축.
- 비정상 종료 후 잘못된 관계 상태가 복구되지 않음.
- 여러 사람의 비동기 메시지로 생성 중 답변이 최신 맥락과 어긋나면 폐기.
