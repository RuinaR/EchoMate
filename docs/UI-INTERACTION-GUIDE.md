## 구현과 입력 감사

[컴포넌트 규칙](UI-COMPONENT-GUIDELINES.md)의 화면별 표가 이번 입력 감사 결과다. 표현 고급 설정은 4개 범위 슬라이더와 2개 선택 그룹으로 바꿨다. 실제 정책에는 없는 잡담 길게/비속어 빈도 단계를 만들지 않았다. 이모지는 답변 문자와 Discord Reaction을 구분한다. 캐릭터 말투/설명, 친밀도, 기억 상태·종류, 호칭 상태, 요약 토글, 만료/알림 유예, 프로필 파일 작업까지 명시적 컨트롤 계약을 사용한다. ID·날짜·내용·검색·삭제 확인과 읽기 전용 출처는 텍스트를 유지한다.

기분/강도 같은 메인 설정은 즉시 저장, 팝업은 드래프트→적용이다. 새 프로필은 같은 이름도 별도 복사본이며 목록의 저장본 번호로 구분한다. 프로필/운영 파일 덮어쓰기 보호·명시 삭제 확인·동의·취소 정책을 보존했다. 모델 선택 목록/서버·채널/관계·기억·예약/진행 화면은 기존 의미를 유지하고 피드백만 공통화했다.

메인 버튼·주요/보조 액션·탭·선택 버튼·토글 배경, 선택 목록의 행, 폼 footer, 프로필 목록 footer, 미리보기 액션에 상태 피드백을 적용했다. 슬라이더/세그먼트/입력에는 focus 강조가 있다. 선택은 체크/표시선/굵은 글자/경계로 hover와 구분한다. 실제 비활성화/중복 방지와 색상 표현을 함께 검증한다. native 파일 선택창과 OS 창 장식은 변경하지 않았다.
