# UI 입력·컴포넌트 규칙 — 2026-10-20

이번 차수는 UI 입력과 피드백만 변경한다. 모델 로더·공정 GPU 큐·사회적 판단·운영 저장소 스키마는 변경하지 않는다. 기존 사회적 품질의 정식 릴리즈 BLOCKED 판정도 유지한다.

## 공통 상태

- 기본: 어두운 CARD 배경, 경계선, 읽기 쉬운 본문색.
- 주요 액션: 보라색. 보조 액션은 어두운 배경.
- hover: 배경/경계가 조금 밝아지고 손 모양 커서. 마우스가 떠나면 해제한다.
- pressed: 톤을 더 낮춰 누름을 표시한다. 마우스 해제/이탈/포커스 이탈 때 잔류하지 않는다.
- selected: 지속되는 보라색 경계. 세그먼트는 체크, 목록은 왼쪽 표시선과 굵은 글자를 추가해 hover와 구분한다.
- focus: Canvas 액션에 포커스 외곽선, 입력/슬라이더/세그먼트에 강조 테두리. 비활성 항목은 키보드 액션에서 제외한다.
- disabled: 낮은 명도·보조색·손 모양 커서 없음. 실제 콜백도 차단한다.
- danger: 붉은 계열 경계/글자와 명확한 삭제·초기화 문구. 기존 확인 입력을 유지하며 저장한 프로필 삭제에도 이름 안내와 명시 확인을 추가한다.
- busy: 적용은 저장 중으로 표시하고 입력·중복 적용·닫기를 잠근다. 원자 저장 중 닫기가 롤백이라는 인상을 주지 않는다. 실패 시 입력/선택을 보존하고 재시도를 허용한다.

동적 hover는 이전·현재 항목만 다시 칠한다. 페이지 전체 재렌더, 새 타이머, GPU/DB 요청을 만들지 않는다. 메인 기존 키보드 이동과 원본 Controller 경계를 유지한다.

## 크기·키보드·검증

입력 영역 기본 폭535px, 폼 폭580px, 간격 약14px이다. 높이는 실제 글꼴 메트릭에 맞추며 긴 폼은 스크롤한다. 설명은 보조색, 오류는 footer 위에 재배치해 버튼과 겹치지 않게 한다. 명시적인 저장 실패에서는 폼이 닫히지 않는다.

슬라이더: 방향키1단위(친밀도0.1), PageUp/Down10단위, Home/End 양 끝. 세그먼트: 방향키·Home/End 선택. 폼: Ctrl+Enter 적용, Esc 닫기. 날짜/메시지처럼 자유 입력이 필요한 필드는 유지한다. Window/Tk 포커스의 실제 사용 감각·native 파일 선택창·모니터 간 DPI 전환·스크린리더는 별도 사용자 확인 대상이다.

## 검증 범위

자동 검사는 자체 withdrawn Tk의 실제 Tcl 콜백·폰트 경계·임시 서명 설정/SQLite를 사용한다. 숨긴 Canvas 창이 1x1로 보고될 때는 요청된 영역과 실제 그린 항목의 경계를 대조하며, 이를 native 사용자 화면 검증으로 주장하지 않는다. 포커스 스타일은 자체 위젯의 focus 상태를 주입한 검사도 포함한다. 실제 Discord/GPU 모델 실행은 이번 UI 차수에서 하지 않는다.
