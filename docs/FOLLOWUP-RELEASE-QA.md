## 기능 연결·개인정보 감사

- Discord는 `/동의` 하나만 정의한다. 본인·서버 ID 검사, 친밀도/기억/요약 독립 선택, 철회/삭제, 앱에서 타인 동의 생성 금지를 보존했다. 원격 명령 정리는 별도 승인 후 다음 허용 연결에서만 수행한다.
- 앱 관계/호칭/기억/예약은 봇 OFF에서도 SQLite를 조회한다. 동의 없음·빈 자료·오류·로딩을 구별하고 이전 비동기 조회가 새로운 선택을 덮지 않는다. 서명 설정/소유자 인증은 유지한다.
- 실제 다중 턴 저장은 모든 참여자의 요약 동의를 요구한다. 과거 비동의 발언 소급 저장·타인 ID/다른 채널 조회를 막는다. 삭제 시 인덱스와 관련 대기 작업을 무효화하고 같은 출처가 재동의 뒤 복원되지 않는지 검사했다. 운영 기존 발췌는 삭제하지 않았다.
- 직접 Unicode 요청은 SDK `add_reaction` 모의 호출까지 확인했다. 대상 ID/hash/권한/범위를 전송 직전 재검사하며 불명확 대상은 임의 추정하지 않는다. 자율 반응은 기존 활동/침묵 정책을 따른다.
- 최종 공통 출력 검사와 자연어 기술 설명을 함께 검사했다. 모든 프로그래밍 언어를 완전 탐지한다는 보장은 없다. 스티커/커스텀 에셋/등록 이미지·GIF 기능을 복구하지 않았다.
- 진행 상황에는 실제 scheduler 대기·처리·완료/취소/실패와 토큰/TTFT/큐 시간, 최근 무응답 이유를 표시한다. 비공개 추론 원문·대화 원문·키는 관찰 통계에 포함하지 않는다.

## 미완료·미검증 및 다음 우선순위

1. 무료·무계정 전체 웹 검색은 제한적이다. 특히 최신 뉴스/가격/법률/패치 등 원문을 안정적으로 확보하지 못한 요청은 확인 불가로 안내한다. 사용자 계정·결제·유료 API를 임의 추가하지 않는다.
2. 요약은 최근40턴/입력 토큰 제한과 출처 부분 일치 검사를 쓴다. 의미 전체의 정확성·아주 긴 그룹 대화 완전성/임의 회상은 인증하지 않는다. 원본 수정은 기존 요약을 무효화하며 삭제 표식 때문에 같은 출처의 자동 재구성이 보수적으로 차단될 수 있다. 새 메시지 정정 사례는 검증했다.
3. 요약 약41초 비용이 있다. 새 요청 시 자동 요약은 취소하지만 명시적 긴 요약은 느릴 수 있다. 장시간 부하와 요약 특화 GPU 취소의 반복 내구성은 추가 확인이 필요하다.
4. 전체 UI 클릭 조합·실제 Windows DPI/키보드·접근성의 사람 관찰,24시간 누수/네트워크 장애·불확실 부분 전송 복구는 미검증이다. 중복 방지를 위해 Ledger 과거 메타데이터는 자동 삭제하지 않으며 장기 저장 크기는 추가 관리 대상이다.
5. 실제 Discord Gateway/권한 변경/명령 등록/Reaction 성공을 이번 모의 검사로 인증하지 않는다. 사용자 조작이나 실서버 시험을 요청하지 않는다.

다음 작업자는 [AI-HANDOFF](AI-HANDOFF.md)→이 문서→[요약 설계](DIALOGUE-SUMMARIES.md)→[검색 설계](WEB-RESEARCH.md)를 읽는다. 성공 증거와 실패 원본을 분리해 유지하며 미확인 항목을 PASS로 승격하지 않는다.

## 재현 명령

작업 루트 PowerShell에서 `$env:PYTHONPATH='src;tests'` 후 `.venv-gemma4/Scripts/python.exe -m unittest discover -s tests -q`를 실행한다. Discord 토큰 없이 임시 DB와 독립 숨긴 Tk를 사용한다. GPU 도구는 봇/앱의 GPU 사용을 중단하고 InstanceLease가 확보된 때만 실행한다. 출력 디렉터리는 새 `local_data/` 하위 경로를 지정하고 기존 결과를 덮지 않는다.

- 신규 기능 GPU: `tools/verify_followup_gpu.py --help`
- 저장 요약 Runtime GPU: `tools/verify_followup_runtime_gpu.py --help`
- 연속 호출/수명: `tools/verify_parallel_gpu.py --help`, `tools/verify_parallel_lifecycle_gpu.py --help`
- 기존 실패 순서: `tools/verify_semantic_gpu.py --help` (비공개 fixture는 업로드 금지)

이 보고서는 사용자 요청20개 보고 항목의 코드·원인·검증·잔여 제한을 모은다. 최종 커밋/전체 검사/공개 검토 결과는 마지막 절과 AI-HANDOFF에 기록한다.
