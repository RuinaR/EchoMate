# EchoMate

친구들과 사용하는 Discord 서버의 **지정된 스레드**에서 동작하는 로컬 AI 대화 봇 프로젝트.

> 상태: **설계 및 저장소 초기화 단계**. 실행 가능한 Discord 봇/AI 학습기는 아직 구현되지 않았습니다.

## 목표
- 1차: 본인이 제공하는 **단일 화자 데이터**를 분석하여 말투·어휘·문장 길이·표현 습관을 모델링한다.
- 지정된 서버/스레드에서만 응답하고, 상황에 따라 발언 또는 침묵을 결정한다.
- 로컬 Ollama를 이용하여 유료 클라우드 추론 없이 동작한다.
- 페르소나를 검색 가능한 리스트박스에서 선택하며, 봇의 서버 닉네임은 `EchoMate(서버닉네임)`으로 표시한다.
- 추후 동의 및 사용 권한이 확인된 다른 친구들의 데이터와 문맥 데이터를 추가할 수 있도록 확장한다.
- 봇임을 명확히 드러내고 실제 사용자 행세를 하지 않는다.

## 현재 범위와 주의
- **과거 서버 전체 기록 자동 수집은 초기 범위에서 제외**한다.
- 단일 화자 데이터로 실제 대화의 원인·상대방 발언을 정확히 복원할 수 없다. 추론된 문맥은 실제 기록으로 취급하거나 정답 라벨로 학습하지 않는다.
- 본인 Discord 데이터 패키지의 메시지는 타인의 발언을 포함하지 않는다. 패키지의 출처/Discord 약관 및 학습 허용 범위를 확인하기 전에는 실제 학습·RAG 인덱싱에 투입하지 않는다.
- 원본 데이터, 모델 가중치, 봇 토큰, .env는 GitHub에 커밋하지 않는다.

## 기술 방향
Python 3.11+ (예정) / discord.py / Ollama / SQLite / 선택적 벡터 검색 / 선택적 QLoRA.
모델 1차 후보: 로컬에서 이미 실행한 Qwen3.5 9B 양자화 모델. 품질/속도/메모리 검증 후 확정.
